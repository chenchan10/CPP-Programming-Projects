## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/CPP-Programming-Projects.git
```

Navigate to the project directory and compile the desired source file using GCC or G++.

Example for Flappy Bird:

```bash
g++ -std=c++17 Flappy-Bird/flappybird.cpp -o flappybird.exe
```

Run the compiled executable on Windows.
